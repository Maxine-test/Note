Glossary

LLM
Stands for Large Language Model — an AI model trained on massive amounts of text to understand and generate human language. Claude, GPT, and Gemini are all LLMs.
Prompt
The instruction or question you type into an AI interface. Used in Cursor, Antigravity, ChatGPT, n8n AI nodes, and elsewhere. The AI generates a response or takes action based on your prompt.
Claude Anthropic
The LLM developed by Anthropic, strong at conversation, analysis, writing, and coding. Available in multiple tiers (Haiku / Sonnet / Opus) and accessible via Claude.ai Chat, Claude Code, Cowork, Cursor, n8n, or the API.
Claude.ai Chat Anthropic
Claude's official web and mobile chat interface (claude.ai). Available as Free, Pro, Team, and Enterprise plans. Supports uploading documents, images, and code; Pro includes web search. MCP lets you connect external tools; Projects lets the AI retain background context across conversations. Suitable for everyone — no technical background needed.
Claude Code Anthropic
Anthropic's terminal AI agent tool (CLI). After installation, type natural language in your local terminal and Claude Code autonomously reads and writes code, executes shell commands, runs tests, and performs Git operations to complete full engineering tasks. Key difference from Cursor: Cursor is an AI assistant inside an editor; Claude Code is an AI agent that autonomously executes tasks in the terminal. Best for developers comfortable with the terminal.
Cowork Anthropic
Anthropic's desktop AI agent app (Beta). Lets users without coding skills describe a goal in natural language, then have an AI agent operate desktop applications to complete it (organising files, filling forms, copying data across apps). Best for non-developers who want to automate everyday computer tasks.
Claude model tiers
Haiku: Lightest and fastest — great for simple Q&A and high-frequency tasks.
Sonnet: Balanced speed and capability — the workhorse for daily development and complex Q&A.
Opus: Most powerful — designed for highly complex reasoning, long document analysis, and research.
Cursor
An AI code editor built on VS Code, with built-in chat, autocomplete, and code-editing features. Supports Claude, Gemini, and GPT as back-end models, plus MCP and Skill extensions.
VS Code
Microsoft's open-source code editor. Cursor is essentially VS Code with AI added on top — the look and feel are very similar.
Antigravity
Google's AI code editor. Primarily uses Gemini but also supports Claude and GPT. Multi-agent design lets agents autonomously plan, write, test, and verify code. Supports MCP and Skill extensions, and has built-in image generation (Imagen 3, etc.).
n8n
An open-source workflow automation tool (similar to Zapier or Make). You build flows by dragging and connecting nodes. Has built-in (or installable) AI nodes for OpenAI and Anthropic — send a prompt to Claude or GPT, then chain the result with Gmail, Slack, databases, APIs, and more.
Gemini
Google's AI model family with multimodal and reasoning capabilities. Available in Cursor, Google AI Studio, and other products.
GPT
OpenAI's language model series (e.g. GPT-4). Powers ChatGPT and is available via Cursor, n8n, or direct API integration into your own apps.
Anthropic
The company behind Claude. Like OpenAI and Google, Anthropic is an AI model provider. Its products include Claude.ai Chat, Claude Code, and Cowork; it also exposes the Claude API for third-party use.
OpenAI
The company behind GPT and ChatGPT. Provides an API used by Cursor, n8n, and custom-built services.
MCP (Model Context Protocol)
A protocol that lets AI assistants connect to external tools and data sources. Claude.ai Chat, Claude Code, Cursor, and Antigravity all support MCP. Install an MCP server and the AI can call databases, APIs, local scripts, and more. Antigravity also offers an MCP Store and pre-built Google Cloud integrations (BigQuery, AlloyDB, etc.). Relationship with Skill: MCP handles where to connect (the hands / tools); Skill handles how to do it (the workflow / method).
Skill
Both Cursor and Antigravity support Skills. A Skill is a reusable instruction set or knowledge package that teaches an AI agent how to perform a specific task (e.g. deploy to staging, code review, write documentation). Stored as Markdown or directories (Cursor: .cursor/skills/, .agents/skills/; Antigravity: .agent/skills/, ~/.gemini/antigravity/skills/). Can be triggered manually (e.g. /skill-name) or applied automatically by the agent based on task semantics. Complements MCP: Skill provides the how (workflow & process); MCP provides the where (external connections & tools).

Claude product line — summary:
Claude.ai Chat (Web / App) → You ask, AI answers. Simplest option; suitable for everyone.
Claude Code (Terminal CLI) → AI agent autonomously completes multi-step engineering tasks. For developers.
Cowork (Desktop app) → AI agent controls your desktop. For non-developers who want to automate daily computer tasks.
All three share the Claude model underneath and all support MCP for external tool connections.
Relationship summary: You use a Prompt in Claude.ai Chat, Claude Code, Cowork, Cursor, Antigravity, ChatGPT, or n8n → each interface forwards your prompt to Claude, Gemini, or GPT. Cursor and Antigravity both support MCP (external tool connections) and Skill (agent workflows and domain knowledge); Claude.ai Chat and Claude Code also support MCP. n8n chains AI with other services into automated workflows. VS Code is the base editor Cursor is built on.
