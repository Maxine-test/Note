名詞說明

LLM
LLM 是 Large Language Model 的縮寫，中文常說「大型語言模型」。指用大量文字訓練、能理解與產生人類語言的 AI 模型；Claude、GPT、Gemini 都屬於 LLM。
Prompt（提示詞）
你輸入給 AI 的指令或問題。在 Cursor、Antigravity、ChatGPT、n8n 的 AI 節點等地方都會用到。AI 根據 prompt 產生回覆或執行動作。
Claude Anthropic
Anthropic 開發的 LLM，擅長對話、分析、寫作與程式。現有多個版本（Haiku / Sonnet / Opus），可透過 Claude.ai Chat、Claude Code、Cowork、Cursor、n8n 或 API 使用。
Claude.ai Chat Anthropic
Claude 的官方網頁與 App 對話介面（claude.ai）。提供免費版與 Pro/Team/Enterprise 付費版。支援上傳文件、圖片、程式碼，Pro 版可搜尋網路。可透過 MCP 連接外部工具；Projects 功能可讓 AI 記住跨對話的背景資訊。適合所有人，不需技術基礎。
Claude Code Anthropic
Anthropic 推出的終端機 AI 代理工具（CLI）。安裝後在本機終端輸入自然語言，Claude Code 會自主讀寫程式碼、執行 shell 指令、跑測試、做 Git 操作，完成完整的工程任務。與 Cursor 的差別：Cursor 是「在編輯器裡的 AI 助手」，Claude Code 是「在終端機裡自主執行任務的 AI 代理」。適合有終端機基礎的開發者。
Cowork Anthropic
Anthropic 的桌面 AI 代理應用程式（Beta）。讓不會寫程式的使用者，用自然語言描述目標，由 AI 代理操控桌面應用程式（如整理檔案、填寫表單、跨應用複製資料）來完成任務。適合想自動化電腦日常操作的非開發者。
Claude 模型版本
Haiku：最輕量快速，適合簡單問答與高頻率任務。
Sonnet：平衡速度與能力，日常開發與複雜問答的主力。
Opus：最強大，適合高度複雜的推理、長文分析與研究任務。
Cursor
以 VS Code 為基礎的 AI 程式編輯器，內建對話、補全、改碼等功能，可選 Claude、Gemini、GPT 為後端模型，支援 MCP 與 Skill 擴充。
VS Code
微軟的程式碼編輯器，開放原始碼。Cursor 是基於 VS Code 的「加上了 AI」的版本，外觀與操作類似。
n8n
開源的工作流自動化工具（類似 Zapier、Make），用節點拖拉串接各種服務。內建或可安裝 OpenAI、Anthropic 等 AI 節點，可把 prompt 送給 Claude、GPT 等，並與 Gmail、Slack、資料庫、API 等串接，做自動化流程。
Gemini
Google 的 AI 模型，具多模態與推理能力。在 Cursor、Google AI Studio、Bard 等產品中可選用。
GPT
OpenAI 的語言模型系列（如 GPT-4）。用於 ChatGPT、Cursor、n8n、或透過 API 整合到自己的應用。
Anthropic
開發 Claude 的公司，與 OpenAI、Google 同屬 AI 模型提供者。旗下產品包含 Claude.ai Chat、Claude Code、Cowork，並開放 Claude API 供第三方使用。
OpenAI
開發 GPT 與 ChatGPT 的公司，提供 API 供 Cursor、n8n、自建服務等呼叫。
MCP（Model Context Protocol）
讓 AI 助理連到外部工具與資料的協定。Claude.ai Chat、Claude Code、Cursor 與 Antigravity 都支援 MCP，裝 MCP 伺服器後，AI 可呼叫資料庫、API、本機腳本等，擴充能力。Antigravity 另提供 MCP Store 與 Google Cloud（BigQuery、AlloyDB 等）預建整合。與 Skill 的關係：MCP 負責「連到哪」（手腳／工具），Skill 負責「怎麼做」（流程／方法）。
Skill（技能）
Cursor 與 Antigravity 都有。Skill 是可重用的指令集或知識包，教 AI 代理如何執行特定任務（例如部署到測試環境、程式碼審查、寫文件）。通常以 Markdown 或目錄形式存放（Cursor：.cursor/skills/、.agents/skills/；Antigravity：.agent/skills/、~/.gemini/antigravity/skills/）。可手動觸發（如 /skill-name）或由代理依任務語意自動套用。與 MCP 互補：Skill 提供「做法與流程」，MCP 提供「對外連線與工具」。

MCP（Model Context Protocol）

flowchart LR
    Cursor[Cursor] <-->|MCP| M[MCP 伺服器]
    Anti[Antigravity] <-->|MCP| M
    CCChat[Claude.ai Chat] <-->|MCP| M
    CCCode[Claude Code] <-->|MCP| M
    M <--> DB[資料庫]
    M <--> API[API]
    M <--> Script[本機腳本]

說明：Cursor、Antigravity、Claude.ai Chat、Claude Code 都支援 MCP；透過 MCP 伺服器可連到資料庫、API、本機腳本等，讓 AI 使用外部工具與資料。

Claude 產品線摘要：
Claude.ai Chat（網頁 / App）→ 你問 AI 答，最簡單，適合所有人。
Claude Code（終端機 CLI）→ AI 代理自主完成多步工程任務，適合開發者。
Cowork（桌面應用）→ AI 代理操控電腦桌面，適合想自動化日常操作的非開發者。
三者底層都是 Claude 模型，都支援 MCP 連接外部工具。
關聯摘要：你用 Prompt 在 Claude.ai Chat、Claude Code、Cowork、Cursor、Antigravity、ChatGPT 或 n8n 下指令 → 各介面把 prompt 送給 Claude、Gemini、GPT 等模型。Cursor 與 Antigravity 都支援 MCP（連外部工具）與 Skill（擴充代理流程與領域知識）；Claude.ai Chat 與 Claude Code 亦支援 MCP；n8n 可把 AI 與其他服務串成自動化流程；VS Code 是 Cursor 的基底編輯器。
